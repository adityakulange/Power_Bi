# Social-Media-Analysis (Interactive Dashboard creation using Power Bi)

## Overview

This project analyzes data and presents key insights through an interactive dashboard. It focuses on tracking important metrics, identifying trends, and simplifying complex data to support data-driven decision-making. 

## Dataset Used
- <a href="https://github.com/adityakulange/Power_Bi/blob/main/Social%20Media%20Project/social_media_engagement1.csv">Social-Media-Dataset</a>

## KPIs
- Goal
Track and analyze content engagement metrics.
- Guidelines
1. Scrape or use APIs from platforms like Instagram or YouTube.
2. Analyze likes, shares, comments, impressions.
3. Visualize data with Power BI/Tableau.
4. Recommend best posting times and content strategies.
